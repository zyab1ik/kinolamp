ЗАЧЕМ НУЖЕН ПЛАГИН

KinoPub внутри Lampa — с пульта

Открой собственный каталог KinoPub в левом меню Lampa: новинки, фильмы, сериалы, поиск и избранное. Или нажми штатную кнопку «Смотреть» в карточке Lampa: однозначно найденный фильм откроется в плеере, сериал — на странице сезонов и серий. Если совпадений несколько, выбери нужный результат. Нужна действующая подписка KinoPub.

Удобно на Samsung Tizen через Media Station X

Если Lampa уже настроена в Media Station X (MSX), открой её внутри MSX и добавь Kinolamp в расширения самой Lampa. Так можно пользоваться подпиской KinoPub в привычном интерфейсе с пультом, когда отдельный клиент KinoPub на телевизор установить сложно.

Samsung Tizen → Media Station X → Lampa → Kinolamp

Плагин также подходит для других устройств с Lampa. Возможности видео и звуковых дорожек зависят от модели телевизора и используемого плеера; конкретную связку проверяй на устройстве. Платформы Media Station X ↗

ПРИМЕР 01 · ФИЛЬМ

Нашёл фильм в каталоге Lampa

Открой его карточку и нажми «Смотреть». Плагин найдёт фильм по названию и году, затем откроет плеер с сохранённой позиции. Если совпадений несколько, выбери подходящий результат. Качество меняется в плеере.

Карточка → Смотреть → Плеер
ПРИМЕР 02 · СЕРИАЛ

Хочешь посмотреть нужную серию

Нажми «Смотреть» в карточке сериала, затем выбери сезон и эпизод. При неоднозначном совпадении сначала выбери нужный сериал. У эпизодов доступны название, кадр, длительность и локальный прогресс, если данные есть. Следующую серию можно выбрать в штатном плейлисте Lampa.

Смотреть → Сезон → Серия → Плеер

VPS раздаёт файлы плагина. В обычном режиме видео идёт напрямую с CDN KinoPub на устройство. Отдельный HLS-прокси помогает совместимым клиентам с проблемными HLS-потоками: он подготавливает плейлист, а не перекодирует видео. Наличие материала и качество зависят от KinoPub и твоей подписки.

НАЧНЁМ С ПОДКЛЮЧЕНИЯ

Подключение по шагам

Нужна действующая подписка KinoPub

Плагин уже добавлен и показывает «200 Рабочий»? Перезагрузи Lampa и начни с шага 3. Этот статус подтверждает загрузку плагина; вход в KinoPub выполняется отдельно.

  1. 01

    Открой Lampa на телевизоре или в браузере

    На Samsung Tizen открой уже настроенную Lampa через Media Station X (MSX). Все следующие шаги выполняются в самой Lampa. В браузере используем cf.lampa.mx ↗. При переходе с HTTP расширения и настройки нужно добавить заново: браузер хранит их отдельно для каждого адреса.

  2. 02

    Добавь Kinolamp в расширения

    В Lampa открой Настройки → Расширения → Добавить. Скопируй адрес ниже, вставь его и перезапусти Lampa.

    Выдели адрес и скопируй его. Открыть kp.js ↗

  3. 03

    Получи код в Lampa

    Вернись из раздела «Расширения» в Настройки → Kinolamp и нажми «Войти в KinoPub». Плагин сам запросит и покажет код. Оставь окно с кодом открытым.

    Client ID и Client Secret уже настроены в плагине. Вручную вводить их или обращаться в поддержку для этого входа не нужно.

  4. 04

    Подтверди код на сайте KinoPub

    На телефоне или в другой вкладке открой адрес из окна плагина — сейчас это kino.watch/device ↗. Войди в свой аккаунт KinoPub.

    В разделе «Активация устройства» введи код, который показывает Kinolamp, в поле «Код устройства» и нажми «Добавить». Код выдаёт плагин в Lampa, а не эта страница.

  5. 05

    Вернись в Lampa и включи фильм

    Подожди сообщения «KinoPub: вход выполнен» — окно закроется автоматически. Затем открой левое меню → KinoPub для отдельного каталога или карточку фильма/сериала в Lampa и нажми «Смотреть». Однозначно найденный фильм откроется в плеере, сериал — на странице сезонов и серий. Если совпадений несколько, выбери нужный результат. Долгое нажатие «Смотреть» открывает другие источники. В старых сборках Lampa выбери «Смотреть» → «KinoPub».

    Для первого просмотра HLS-прокси оставь выключенным. Его настройка нужна только при проблемах воспроизведения на конкретном устройстве.

ПОСЛЕ ВХОДА

Как пользоваться Kinolamp

01 · НАЙТИ КИНО

Открой каталог KinoPub

Выбери KinoPub в левом меню Lampa. Сверху доступны «Новинки», «Фильмы», «Сериалы», «Поиск» и «Избранное». Для поиска введи минимум три символа. Кнопка «Фильтры» задаёт жанр и качество в каталоге; озвучку выбирай в плеере.

Левое меню → KinoPub → Поиск или раздел
02 · СОХРАНИТЬ НА ПОТОМ

Удерживай OK на карточке

В меню закладок выбери папку аккаунта KinoPub. Если папок ещё нет, отдельное действие создаст «Избранное» и добавит материал. Сохранённые фильмы доступны через «Избранное» в каталоге. Повторное долгое нажатие позволяет удалить материал из конкретной папки.

Карточка → удерживать OK/Enter → Папка
03 · СМОТРЕТЬ СЕРИАЛ

Выбери сезон и серию

Сохранённая позиция подхватывается автоматически в поддерживаемом плеере. Следующая/предыдущая серия выбирается через штатный плейлист Lampa. Автопереход включается в настройках плейлиста самой Lampa; отдельного переключателя Kinolamp нет.

Прогресс хранится на этом устройстве. Общий сброс находится в «Настройки → Kinolamp → Дополнительно» и требует подтверждения.

Сезон → Серия → Плеер → Следующая серия
04 · РАЗОБРАТЬ ЗАВИСАНИЕ

Включи локальную диагностику

Открой «Настройки → Kinolamp → Дополнительно → Диагностика воспроизведения», включи сбор и заново запусти видео. После проблемы вернись в это меню и открой отчёт. API, свой прокси и последний CDN проверяются отдельной кнопкой вручную.

До 120 событий хранятся только в памяти. Выключение или перезапуск очищает их. JSON скачивается по нажатию, если клиент поддерживает загрузку файлов. Доступность показателей зависит от плеера; HEAD/CORS-проверка CDN не измеряет скорость видео и не доказывает причину зависания.

Настройки → Kinolamp → Дополнительно → Диагностика

Прогресс между устройствами пока не синхронизируется. Отдельная постоянная память озвучки для каждого сериала и сезона ещё планируется. Наличие материала, звуковых дорожек и субтитров зависит от KinoPub и плеера.

⌁

Прокси — по необходимости

Для прямого просмотра HLS-прокси не нужен. Если он требуется твоему устройству, включи его на сервере, а затем укажи HTTPS-адрес и ключ в разделе «Настройки → Kinolamp → Дополнительно».

◇

Токены остаются на устройстве

Плагин хранит данные входа в хранилище Lampa. Устанавливай только проверенные расширения: скрипты внутри одной Lampa могут иметь доступ к этим данным.

Плагин показывает «404» или не загружается?

Проверь адрес плагина: он должен начинаться с https:// и заканчиваться на /kp.js. Открой его в отдельной вкладке — должен появиться JavaScript. Затем перезапусти Lampa. Если ошибка остаётся, проверь доступность сервера и блокировки браузера. KinoPub API также должен разрешать запросы из используемой сборки Lampa.

Не вижу KinoPub в левом меню или новых пунктов?

Полностью перезапусти Lampa, чтобы загрузить обновлённый плагин. Проверь адрес расширения и актуальность сборки Lampa. Каталог также открывается через «Настройки → Kinolamp → Дополнительно → Открыть каталог KinoPub». Для нативных страниц нужна сборка с поддержкой Activity.

Где взять код? На сайте пустое поле. А если код истёк?

Код появляется в Lampa после нажатия «Настройки → Kinolamp → Войти в KinoPub». На сайте KinoPub его только подтверждают. Если видишь старые поля Client ID/Secret, перезапусти Lampa для загрузки новой версии плагина. Если код истёк, закрой окно в Lampa и нажми «Войти в KinoPub» заново — появится новый код. Если сервер не принимает общий клиент, плагин покажет отдельное сообщение; проверь обновления Kinolamp или повтори позже.
