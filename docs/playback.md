# Локальный прогресс просмотра

Kinolamp сохраняет позицию на устройстве в `kp_self_progress`, независимо от
облачной Timeline Lampa. На VPS или в KinoPub эти записи не отправляются.
Сохраняется не более 500 последних записей. Идентификатор содержит ID материала
KinoPub, тип видео, сезон и media ID (или номер эпизода/части, если API не дал ID).
Название и подписанный URL в идентификации не участвуют.

При повторном открытии незавершённого видео доступны «Продолжить», «Начать
сначала» и «Сбросить прогресс». В меню серий/частей показывается локальная
позиция или «Просмотрено». Видео считается просмотренным при событии `ended`
либо достижении 95% длительности. Сброс одной записи находится в меню видео,
полный сброс — в Настройки → Kinolamp и требует явного выбора удаления.

События плеера сохраняются не чаще раза в пять секунд, дополнительно — при
паузе, завершении и закрытии. При продолжении исходная запись сохраняется,
пока плеер не подтвердит перемотку; открытие другого источника отключает запись
Kinolamp. Невалидные/бесконечные значения не записываются, заполненное локальное
хранилище не останавливает воспроизведение.

Поддерживаются встроенный плеер Lampa и Tizen через `Player.listener`,
`PlayerVideo.listener` (`timeupdate`, `pause`, `ended`) и `PlayerVideo.to`.
Используется также локальный `timeline.handler` плеера; `Lampa.Timeline.update`
не вызывается. Отдельные внешние Android/Apple-плееры могут не возвращать эти
события. Для сборок без необходимого API продолжение явно обозначается как
неподдерживаемое. Проверка на физическом телевизоре остаётся обязательной
перед заявлением совместимости с конкретной моделью.

Контракт проверен по исходникам Lampa: [player](https://github.com/yumata/lampa-source/blob/main/src/interaction/player.js),
[video](https://github.com/yumata/lampa-source/blob/main/src/interaction/player/video.js),
[timeline](https://github.com/yumata/lampa-source/blob/main/src/interaction/player/timeline.js).

## Следующая серия

Сезоны и эпизоды формируют штатный плейлист Lampa в числовом порядке, включая
специальный сезон 0. Следующая/предыдущая серия выбирается с пульта или через
меню плейлиста. «Следующая серия автоматически» в настройках Kinolamp — это
общая настройка `playlist_next` Lampa, а не скрытое переопределение поведения
остальных источников. Выключение запрещает автоматический переход, но сохраняет
ручную навигацию. У последней серии нет следующей и зацикливания.

URL не загружаются заранее: lazy-resolver штатного плейлиста запрашивает свежий
материал KinoPub, затем media-links при необходимости и новый HLS-ticket.
После ухода с эпизода его resolver восстанавливается, поэтому обратный переход
тоже не использует старую ссылку. Ограничение качества и выбранная для прокси
озвучка переносятся; если дорожки нет, выбирается первая с уведомлением. Если
нет качества в выбранном ограничении, переход останавливается. В прямом режиме
штатный плеер Lampa переносит свои аудиопараметры.

Ошибка закрывает незавершённый native-loader, без бесконечного автоповтора.
Ручной выход и запуск другого источника отменяют результат ожидающих запросов;
запоздавший ответ не должен открыть новый плеер. Отдельные внешние плееры,
принимающие только JSON-плейлист без функций, не поддерживают такой resolver.
Для сборок без `Player.listener`/`Player.close` остаётся одиночное воспроизведение.

Контракт lazy URL и native-переходов: [playlist](https://github.com/yumata/lampa-source/blob/main/src/interaction/player/playlist.js)
и обработчик `Playlist.listener/select` в исходниках `Player`.
